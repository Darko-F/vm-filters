# VM Smart Filters 1.1.2

Install this entire package ZIP through Joomla's extension installer. It contains the VM Smart Filters site module and System - VM Property Filters plugin. Requires VirtueMart 4.8.4+, Joomla 4.4+ and the PHP version required by your installed Joomla/VirtueMart release (extension minimum PHP 8.1).

For dimension and weight filtering, enter the product measurements and their units, then attach public Property custom fields referencing product_length, product_width, product_height or product_weight. Publish the module on your VirtueMart category pages. Enter a minimum and/or maximum and press Show products.

The companion plugin is enabled on its first installation. Existing module settings are retained when installing over 1.0.x. Uninstall the package as a whole. Enter your protected-update Download Key under System > Update Sites > VM Smart Filters Package Updates.

Full instructions: modules/mod_vm_smartfilters/README.md after installation, or https://github.com/Darko-F/vm-filters
